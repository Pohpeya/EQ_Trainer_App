โฟลเดอร์ samples สำหรับใส่ไฟล์เสียงเครื่องดนตรีจริง (Real Audio Samples)
==============================================================

คุณสามารถนำไฟล์เสียงเครื่องดนตรีจริงมาใส่ในโฟลเดอร์นี้ เพื่อให้เว็บแอปพลิเคชันดึงไปเล่นแทนเสียงสังเคราะห์ได้ทันที:

ไฟล์ที่แนะนำ:
- kick.wav : เสียงกระเดื่องจริง (ความยาว 0.3 - 0.8 วินาที เป็น One-shot 1 ที)
- snare.wav : เสียงสแนร์จริง (ความยาว 0.4 - 1.0 วินาที)
- hihat.wav : เสียงไฮแฮทจริง (ความยาว 0.2 - 0.5 วินาที)

รูปแบบไฟล์ที่แนะนำ:
- นามสกุล: .wav หรือ .mp3
- Sample Rate: 44.1 kHz หรือ 48 kHz (16-bit หรือ 24-bit PCM)

หมายเหตุเกี่ยวกับการเปิดใช้งาน:
- หากเปิดเว็บผ่าน Local Web Server (เช่น VS Code Live Server หรือ http-server) ระบบจะดึงไฟล์จากโฟลเดอร์นี้มาเล่นอัตโนมัติ
- หากเปิดด้วยการดับเบิลคลิก index.html ตรงๆ สามารถลากไฟล์ (Drag & Drop) วางลงบนหน้าต่างเว็บ หรือกดปุ่ม "📁 นำเข้าเสียงของตัวเอง" ได้ทันทีเช่นกัน
