# 🎛️ EQ Master Trainer (เครื่องมือฝึกฝนการปรับ EQ และพัฒนาหูนักมิกซ์เสียง)

แอปพลิเคชันสำหรับการเรียนรู้ ฝึกฝนการฟัง และปรับแต่งย่านความถี่เสียง (Equalizer) ของเครื่องดนตรียอดนิยมระดับสากล พัฒนาขึ้นด้วยเทคโนโลยี **HTML5 Web Audio API** ทำงานได้ทันทีบนเว็บเบราว์เซอร์ (Google Chrome, Microsoft Edge, Safari, Firefox) โดยไม่ต้องติดตั้งโปรแกรมหรือเซิร์ฟเวอร์เสริม

---

## 🚀 วิธีการเปิดใช้งาน (How to Run)
1. เข้าไปที่โฟลเดอร์ `EQ_Trainer_App`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์ (Chrome หรือ Edge แนะนำเป็นพิเศษ)
3. กดปุ่ม **"▶ เล่นเสียง (Play)"** ด้านบนเพื่อเริ่มฟังเสียงจำลองเครื่องดนตรีแบบเรียลไทม์

---

## 🌟 ฟีเจอร์เด่นของแอปพลิเคชัน

### 1. เครื่องดนตรีสากลและชิ้นกลองชุดยอดนิยม (Multi-Instrument & Drums Collection)
- **🥁 KICK**: เจาะลึกความกระแทก Punch (80-100Hz) มวลต่ำ Sub 50Hz และหัวคลิก (3.5kHz)
- **🥁 SNARE**: ครบเครื่องทั้งเนื้อไม้ตัวถังสแนร์ (200Hz) และความซู่ซ่าของสายสะแนร์ (5k-8kHz)
- **✨ HIHAT**: ประกายความสว่าง (Air & Shimmer 10kHz+)
- **🥁 TOM 1**: กลองทอมใบเล็ก (10"-12") โทนเสียงสูง เนื้อเสียง 200-240Hz หัวไม้คมชัด 4.2kHz
- **🥁 TOM 2**: กลองทอมใบกลาง (12"-13") สะพานเชื่อมเสียงท่อนส่งกลอง เนื้อเสียง 160Hz
- **🥁 FLOOR TOM**: กลองทอมใบใหญ่ตั้งพื้น (16"-18") มวลต่ำลึก 70Hz และน้ำหนักกระแทกอก 110Hz
- **🎙️ OVERHEAD L**: ไมค์สเตอริโอฝั่งซ้าย ไฮแฮท แฉ Crash ซ้าย ความโปร่งกว้างสเตอริโอ
- **🎙️ OVERHEAD R**: ไมค์สเตอริโอฝั่งขวา ฉาบ Ride กระดิ่ง Ride Bell (3.5kHz) และความหรูหราฝั่งขวา
- **🎸 เบสไฟฟ้า (Electric Bass)**: การเดินเบสแบบ Funky groove พร้อมซับเบสและความชัดของตัวโน้ต
- **🎸 กีตาร์โปร่ง (Acoustic Guitar)**: การสตรัมคอร์ดแจ๊ส/ป๊อป พร้อมความอบอุ่นของเนื้อไม้
- **⚡ กีตาร์ไฟฟ้า (Electric Guitar)**: เสียงแตก Overdrive/Crunch ผ่านตู้แอมป์จำลอง
- **🎤 เสียงร้องสากล (Lead Vocals)**: เมโลดี้เสียงร้องสังเคราะห์ Formants สระ [a], [o] พร้อม Vibrato
- **🎹 เปียโนและคีย์บอร์ด (Acoustic Piano)**: คอร์ดเปียโนกังวานและเสียงหัวค้อนกระทบสาย
- **📁 นำเข้าไฟล์ของตนเอง (.wav, .mp3)**: สามารถลากไฟล์เสียงเพลงหรือ Stem จริงของคุณเข้ามาฝึกปรับได้ทันที!

### 2. อีควอไลเซอร์ 2 รูปแบบระดับสตูดิโอ (Dual-Mode Studio Equalizer)
สามารถคลิกสลับโหมดการทำงานได้ตามต้องการที่แถบด้านบน:
* **🎛️ Parametric EQ Mode (FabFilter Pro-Q Style)**:
  * **Interactive Drag & Drop**: สามารถคลิกและลาก 8 จุดบนกราฟความถี่ได้อิสระ
  * **ลากซ้าย - ขวา**: ปรับย่านความถี่ (Frequency 20 Hz – 20,000 Hz) แบบ Logarithmic
  * **ลากขึ้น - ลง**: ปรับเพิ่มหรือลดเกน (Gain -18 dB ถึง +18 dB)
  * **หมุนลูกกลิ้งเมาส์ (Scroll Wheel)**: ปรับความแคบ/กว้างของย่าน (Q-Factor 0.2 ถึง 12.0)
  * **ดับเบิลคลิก**: รีเซ็ตเกนจุดนั้นกลับเป็น 0 dB ทันที
  * **Solo Band (Audition Mode)**: ปุ่ม 🎧 เพื่อฟังเจาะจงเฉพาะความถี่จุดนั้น

* **📊 Graphic EQ Mode (Console 10-Band ISO Faders + Real-Time RTA)**:
  * **10 คันโยกย่านความถี่มาตรฐานสากล**: 31.5 Hz, 63 Hz, 125 Hz, 250 Hz, 500 Hz, 1 kHz, 2 kHz, 4 kHz, 8 kHz, 16 kHz
  * **ดึงย่านไหนขึ้น กราฟบนจอจะขยับตามแบบเรียลไทม์**: เชื่อมโยงกับกราฟสเปกตรัม RTA บนหน้าจอทันที สามารถดึงคันโยกบนแร็คหรือลากบนจอกราฟได้โดยตรง
  * **มิเตอร์ไฟ LED RTA สดประจำแต่ละคันโยก**: มีไฟสัญญาณกระพริบตามระดับพลังงานเสียงของย่านนั้นแบบเรียลไทม์ (Live Spectrum Energy)
  * **⭐ ค่ามาตรฐานประจำเครื่องดนตรี (Standard Default EQ)**: เมื่อเลือกเครื่องดนตรีใด ระบบจะโหลดรูปทรงกราฟ EQ มาตรฐานระดับสตูดิโอที่เหมาะสมกับเครื่องดนตรีนั้นๆ ให้เป็นค่าตั้งต้นทันที! (เช่น กระเดื่องจะถูกจูน 60Hz แน่น, 500Hz scoop คัตออก, 4kHz ดันหัวคลิกไว้ให้แล้ว)
  * **ปุ่มรีเซ็ต**: สามารถกด **"⭐ โหลดค่ามาตรฐานเครื่องนี้ (Standard Default)"** หรือ **"🔄 แฟลตทั้งหมด (Flat 0 dB)"** เพื่อเปรียบเทียบความแตกต่างได้อย่างรวดเร็ว

* **Real-time Spectrum Analyzer (RTA)**: วิเคราะห์สเปกตรัมความถี่ FFT จริง 60 FPS
* **Bypass EQ (A/B Test)**: ปุ่มสลับฟังเทียบระหว่าง **เสียงดิบ (Bypass)** กับ **เสียงที่ผ่านการปรับ EQ**
* **Safety Limiter**: มีระบบ Compressor/Brickwall Limiter อัตโนมัติ ป้องกันไม่ให้เสียงแตกและปกป้องลำโพง/หูฟัง

### 3. สารานุกรมเนื้อเสียงที่ถูกต้อง ("เนื้อเสียงที่ถูกต้องคืออะไร?")
ในแต่ละเครื่องดนตรี ระบบจะแสดงแถบความถี่สีสันสดใส และการ์ดวิเคราะห์เนื้อเสียงอย่างละเอียด:
- **🎯 เนื้อเสียงที่ถูกต้อง**: โทนที่ควรจะเป็น เช่น มวลต่ำ, ความอุ่น, เสียงกล่องกระดาษ, ความโปร่ง
- **🔺 ถ้าบูสต์มากเกินไป**: จะเกิดผลเสียอะไร เช่น บวมทึบ (Muddy), แสบแก้วหู (Harsh), ก้องอู้อี้ (Boxy)
- **🔻 ถ้าคัตมากเกินไป**: จะสูญเสียอะไร เช่น เสียงบางแห้ง ขาดน้ำหนัก ไร้ชีวิตชีวา
- **💡 Pro Tip**: เคล็ดลับการมิกซ์เสียงจากซาวด์เอนจิเนียร์ระดับโลก
- **🔊 คลิกเพื่อฟังเจาะจง (Click-to-Audition)**: เพียงคลิกที่การ์ดย่านใด ระบบจะจูน EQ ไปยังย่านนั้นทันที

---

### 4. หูทองคำ: แบบฝึกหัดทายย่านเสียง (Golden Ears Quiz)
- ฝึกหูให้แยกแยะความถี่ได้อย่างแม่นยำเหมือน Sound Engineer
- ระบบจะสุ่มบูสต์หรือคัตย่านความถี่ปริศนา
- ผู้ใช้กดปุ่มฟังเทียบเสียงปกติ (Flat) กับเสียงปริศนา แล้วทายว่าเป็นย่านความถี่ใด
- ระบบให้คะแนน, สถิติทายถูกต่อเนื่อง (Streak), พร้อมเฉลยและอธิบายเนื้อเสียงของย่านนั้นทันที
- เลือกระดับความยากได้ 3 ระดับ: มือใหม่ (3 ย่าน), ปานกลาง (5 ย่าน), โปร (8 ย่าน)

## 🛡️ เทคโนโลยีและความปลอดภัยของระบบเสียง
- ขับเคลื่อนด้วย **Web Audio API BiquadFilterNode** และ **AnalyserNode**
- มีระบบ **Dynamic Compressor / Brickwall Safety Limiter** ในตัว เพื่อปกป้องลำโพงและหูฟังจากการบูสต์เสียงที่แรงเกินไป ไม่ให้เกิดอาการลำโพงแตก (Digital Distortion Clipping)
