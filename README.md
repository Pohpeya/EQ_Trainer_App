# 🥁 EQ Master Trainer - ชี้เป้าฝึกฟังย่านเสียงกลอง

แอปพลิเคชันสำหรับการเรียนรู้และฝึกฝนการฟังย่านความถี่เสียง (Equalizer) ของเสียงกลองจริงในสตูดิโอ พัฒนาด้วยเทคโนโลยี **HTML5 Web Audio API** ทำงานได้ทันทีบนเว็บเบราว์เซอร์ ทั้งคอมพิวเตอร์และโทรศัพท์มือถือ (แนวตั้งและแนวนอน)

---

## 🚀 วิธีการเปิดใช้งาน (How to Run)
1. เข้าไปที่โฟลเดอร์ `EQ_Trainer_App`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` บนเว็บเบราว์เซอร์
3. กดปุ่ม **"▶ เล่น LOOP"** เพื่อเริ่มฟังเสียงกลองวนลูป
4. กดเลือกชิ้นกลอง (8 ชิ้นที่มีตัวอย่างเสียงจริง)
5. ปรับย่านเสียงสำคัญที่ต้องการได้ทันที โดยกดปุ่ม **[+6 dB (เร่ง)]**, **[-6 dB (ตัด)]**, หรือเลื่อนแถบสไลเดอร์เพื่อฟังความเปลี่ยนแปลง

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. เครื่องดนตรีเสียงจริง 8 ชิ้น (8 Real Drum Loop Instruments)
- **🥁 KICK**: กระเดื่อง (Sub 50Hz, Punch 90Hz, Mud 380Hz, Attack 3.5kHz)
- **🥁 SNARE**: สแนร์ (Body 200Hz, Ring 650Hz, Snap 2.8kHz, Sizzle 7.5kHz)
- **✨ HI-HAT**: ไฮแฮท (Rumble 150Hz, Body 700Hz, Chik 4.5kHz, Air 12kHz)
- **🥁 TOM 1**: ทอม 1 (Body 220Hz, Cardboard 550Hz, Attack 4.2kHz)
- **🥁 TOM 2**: ทอม 2 (Thump 160Hz, Mud 420Hz, Attack 3.6kHz)
- **🥁 FLOOR TOM**: ฟลอร์ทอม (Sub Boom 70Hz, Weight 110Hz, Hollow 330Hz, Slap 3.2kHz)
- **🎙️ OVERHEAD L**: ไมค์โอเวอร์เฮดซ้าย (Low Bleed 180Hz, Cymbal Body 800Hz, Harshness 4.5kHz, Shimmer 12kHz)
- **🎙️ OVERHEAD R**: ไมค์โอเวอร์เฮดขวา (Low Bleed 180Hz, Ride Body 900Hz, Ride Bell 3.5kHz, Sheen 12kHz)

### 2. ชี้เป้าย่านเสียงสำคัญบนกราฟ (Target Pinpointing on RTA Spectrum)
- เส้นประเลเซอร์และป้ายชี้เป้าความถี่สำคัญของเครื่องดนตรีชิ้นนั้นโดยตรง
- จุดปรับแบบโต้ตอบ (Interactive Node) บนเส้นกราฟ EQ สามารถลากขึ้น-ลงเพื่อปรับเกนได้ทันที
- สเปกตรัม RTA แบบเรียลไทม์ 60 FPS แสดงการตอบสนองความถี่จริงของเสียงกลองที่กำลังเล่น

### 3. แผงควบคุมกระชับ อยู่ใกล้กัน และเข้าใจง่าย (Unified Sweet-Spot Control Deck)
- รวมเครื่องมือปรับและคำแนะนำการฟังไว้ด้วยกันในการ์ดเดียว
- ปุ่มกดฟังทันที **[-6 dB (ตัด)]**, **[0 dB (เดิม)]**, **[+6 dB (เร่ง)]** เพียงแตะครั้งเดียวก็ได้ยินความแตกต่างทันที
- สไลเดอร์ปรับเกนละเอียด (-12 dB ถึง +12 dB)
- ข้อสังเกตสั้น 2 บรรทัด (🔺 ถ้าเร่ง / 🔻 ถ้าตัด) ไม่ต้องอ่านยาว

### 4. ปุ่มเปรียบเทียบเสียง A/B (Bypass EQ)
- กดปุ่ม **⚡ BYPASS** เพื่อสลับฟังระหว่างเสียงต้นฉบับดั้งเดิม กับเสียงที่ผ่านการปรับ EQ ช่วยให้ผู้เรียนตรวจสอบได้ทันทีว่าการปรับ EQ นั้นช่วยให้เสียงดีขึ้นหรือแย่ลง
